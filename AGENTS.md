# AI Engineer — инструкции для агента

Это автономный справочник и учебник «Как стать AI Engineer». Читатель — PL/SQL-разработчик, который осваивает Python и ML с нуля и будет искать работу за пределами русскоязычного рынка. Репозиторий: `https://github.com/maart/ai-engineer`; основная ветка `main`, remote `origin`.

## Структура и среда

- `ai-engineer.html` — единственный основной артефакт: разметка, CSS, данные и JavaScript внутри.
- `validate.js` — dev-скрипт проверки. `README.md` — запуск. Лицензия MIT.
- Нет `package.json`, сборщика, CI или runtime-зависимостей. Не добавляй их.

## Команды

```bash
node validate.js
open ai-engineer.html
python3 -m http.server 8002
```

Валидатор должен завершаться строкой `RESULT: PASS`. Он проверяет данные (`validateData()`), прогоняет самопроверку на заведомо сломанных данных и проверяет разметку и футер. `node validate.js --links` дополнительно открывает все ссылки ресурсов и ленты; запускай его на машине с доступом в интернет.

## Модель данных

Все данные — в разделе 2 скрипта. Текст `L` — всегда объект `{ ru, en, es }`. Id — kebab-case, уникальны в своём списке.

- `BLOCKS`: `id`, `order`, `priority` (`must` — обязательно для первой работы, `basic` — базово, `plus` — плюс), `title: L`, `summary: L`. Девять блоков из «Карты навыков AI-инженера (2026)»; новый блок добавляй только по просьбе пользователя.
- `TOPICS`: `id`, `block`, `title: L`, `what: L` (что это), `why: L` (зачем AI-инженеру), `fromSql?: L` (как это выглядит для SQL/PL-SQL-разработчика: аналогии, отличия, где опыт с БД — преимущество), `concepts` (id терминов глоссария), `example?: { lang, code }` (`lang` из `CODE_LANGS`; код общий для всех языков, комментарии в нём лучше на английском), `resources: [{ title, url, kind, lang }]` (минимум один; `kind` из `RESOURCE_KINDS`, `lang` — язык самого ресурса), `practice: L` (мини-задание), `prereq` (на какие темы опирается, без циклов), `related`, `checked` (дата сверки с актуальным состоянием).
- `GLOSSARY`: `id`, `term: L`, `definition: L`, `topics`.
- `CHANGELOG`: `date`, `title: L`, `text: L`, `topics`, `source` (https). Записи — от новых к старым.

Добавляя термин в `concepts` темы, добавь тему и в `topics` термина.

## Правила изменений

- Сохраняй проект однофайловым: не выноси CSS, JS или данные из `ai-engineer.html`.
- **Три языка.** Каждый текст интерфейса (`UI`) и каждое текстовое поле данных — объект `{ ru, en, es }`, все три заполнены. Русский — язык по умолчанию. Термины на английском, если так говорят в индустрии (embeddings, RAG, fine-tuning); в русском и испанском тексте при первом упоминании давай английский термин в скобках. Испанский — европейский (Испания).
- Добавляя или меняя тему, обновляй все три языка в одном коммите. Не оставляй один язык устаревшим.
- У каждой темы есть дата `checked` (ГГГГ-ММ-ДД): ставь текущую дату, когда сверил содержание и ссылки с актуальным состоянием технологий.
- Ресурсы — только https-ссылки на первоисточники (официальная документация, курсы, статьи авторов). Перед добавлением открой ссылку и убедись, что она жива.
- Значимые новости индустрии записывай в `CHANGELOG` с датой, источником и связанными темами.
- При каждом изменении `ai-engineer.html` обновляй дату и время в футере по Мадриду (CET/CEST): бери их из `TZ=Europe/Madrid date "+%Y-%m-%d %H:%M"`, не выдумывай.
- При каждом коммите, который меняет HTML, увеличивай версию MVP в футере.
- После каждого изменения выполняй `node validate.js`, затем `git add`, `git commit` и `git push` в `main`. Не добавляй посторонние файлы.

## Устройство скрипта

- В начале `<script>` — оглавление; разделы отмечены строками `// ═══════ N. …`. Данные клади в раздел данных, код — в раздел своей части интерфейса.
- Строки интерфейса берутся через `t(key, lang)` из `UI`; в разметке — атрибут `data-i18n`.
- Поля `state` сохраняй через `persist("имяПоля")` (ключ `aie:имяПоля` в `localStorage`), читай через `readStored` и нормализуй при чтении (`normalizeLang`, `normalizeTheme` и т.п.).

## Питфоллы

- Валидатор извлекает первый `<script>` и ожидает маркер `const dataIssues = validateData();`; код, работающий с DOM, выполняется только при `typeof document !== "undefined"`.
- Прогресс и заметки хранятся в `localStorage`; не рассчитывай на состояние браузера при проверке.
