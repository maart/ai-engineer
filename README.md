# Как стать AI Engineer

Офлайн-справочник и учебник по профессии AI Engineer на трёх языках: русском (по умолчанию), английском и испанском. Один HTML-файл без зависимостей: открыть двойным кликом, изучать темы, отмечать прогресс, вести заметки. Содержание пополняется по мере развития технологий.

## Запуск

```bash
open ai-engineer.html                # просто открыть в браузере
node validate.js                     # проверка данных: должно быть RESULT: PASS
python3 -m http.server 8002          # если нужен локальный сервер: http://localhost:8002/ai-engineer.html
```

## Файлы

- `ai-engineer.html` — всё приложение: разметка, стили, данные и код.
- `validate.js` — проверка данных и разметки.
- `AGENTS.md` — правила для ИИ-агента, который пополняет справочник.
- `docs/plans/` — планы разработки.
