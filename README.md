# Как стать AI Engineer

Офлайн-справочник и учебник по профессии AI Engineer на трёх языках: русском (по умолчанию), английском и испанском. Один HTML-файл без зависимостей: открыть двойным кликом, изучать темы, отмечать прогресс, вести заметки. Содержание пополняется по мере развития технологий.

## Что внутри

- **Карта навыков**: 9 блоков и 55 тем, от Python до портфолио. В каждой теме: что это, зачем AI-инженеру, раздел «Для SQL-разработчика» (аналогии с PL/SQL и где опыт с БД даёт фору), понятия, пример кода, ресурсы, практическое задание, связи с другими темами.
- **Три языка**: русский, английский, испанский. Переключатель в шапке, выбор запоминается.
- **Мой прогресс**: статус каждой темы (не начато, изучаю, понял, применил), заметки к темам, «Входящие» для быстрых ссылок и мыслей, сохранение и загрузка резервной копии в JSON.
- **Глоссарий**: 57 терминов, у каждого перевод на все три языка — пригодится на собеседованиях.
- **Лента изменений**: датированные новости индустрии со ссылками на первоисточники и затронутые темы.
- **Свежесть**: у темы есть дата проверки; если ей больше 120 дней, тема помечается «Проверить актуальность», и такие темы можно отфильтровать на главной.
- **Поиск** по темам и терминам на текущем языке и по английским терминам.

Прогресс, заметки и входящие хранятся в браузере (localStorage). Регулярно сохраняйте резервную копию на странице «Мой прогресс».

## Запуск

```bash
open ai-engineer.html                # просто открыть в браузере
node validate.js                     # проверка данных: должно быть RESULT: PASS
node validate.js --links             # плюс проверка всех ссылок (нужен интернет)
python3 -m http.server 8002          # если нужен локальный сервер: http://localhost:8002/ai-engineer.html
```

## Файлы

- `ai-engineer.html` — всё приложение: разметка, стили, данные и код.
- `validate.js` — проверка данных и разметки.
- `AGENTS.md` — правила для ИИ-агента, который пополняет справочник.
- `docs/plans/` — планы разработки.
